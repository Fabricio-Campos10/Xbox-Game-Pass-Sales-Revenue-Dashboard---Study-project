# Xbox Game Pass Sales & Revenue Dashboard

## Sobre o projeto

Este projeto consiste no desenvolvimento de um dashboard interativo no Microsoft Excel para análise de assinaturas e receitas do Xbox Game Pass. O objetivo é transformar dados tabulares em informações visuais que facilitem a interpretação dos resultados e apoiem a análise de desempenho comercial.

## Principais análises

- **Receita:** análise do faturamento gerado pelas assinaturas.
- **Planos de assinatura:** comparação entre diferentes planos e periodicidades de cobrança.
- **Renovação automática:** análise das assinaturas com e sem renovação automática.
- **Serviços adicionais:** avaliação das receitas relacionadas ao EA Play Season Pass e ao Minecraft Season Pass.
- **Indicadores visuais:** consolidação de informações relevantes por meio de gráficos e elementos visuais.

## Ferramentas utilizadas

- Microsoft Excel
- Organização e tratamento de dados
- Fórmulas e cálculos para análise
- Tabelas-resumo
- Dashboards e visualização de dados

## Objetivo do projeto

Aplicar conceitos de análise de dados e Business Intelligence (BI) para transformar informações de assinaturas em indicadores visuais, facilitando a identificação de padrões e a compreensão do desempenho comercial.

O projeto também demonstra habilidades de organização de dados, construção de indicadores, visualização de informações e desenvolvimento de dashboards no Excel.

## ⚠️ Aviso

este projeto possui finalidade exclusivamente educacional e demonstrativa. Os dados utilizados podem ser fictícios ou simulados e não representam informações oficiais de vendas ou faturamento da Microsoft ou do Xbox.

## 📁 Como visualizar

1. Baixe o arquivo `DashBoard_vendas_xbox.xlsx` disponível neste repositório.
2. Abra o arquivo no Microsoft Excel.
3. Acesse a aba **Dashboard** para visualizar os indicadores e gráficos.
4. Explore as demais abas para consultar os dados e os cálculos utilizados na construção do painel.
